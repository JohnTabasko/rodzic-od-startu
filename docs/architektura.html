🖥 Backend (Express + TypeScript)

Auth

konta anonimowe + OIDC (JWKS Google/Apple, RS256·iss·aud·exp) → nasz JWT HS256 90 dni; w bazie tylko SHA-256 tokenu

Pairing 💑

kod 6-znakowy · rozłączenie w każdej chwili · widoczność: kalendarz+checklisty wspólne, reszta prywatna

Sync

last-write-wins per rekord (ON CONFLICT) · tombstone usunięć · ?since= przyrostowo

Asystent 🤖

guardrails → retrieval semantyczny (offline n-gramy / OpenAI embeds) → LLM z wymuszonym cytatem docId · log jakości z hashami

Społeczność 👥

automoderacja porad medycznych/obraźliwych → kolejka człowieka (ADMIN_TOKEN) · pseudonim autorów

Hardening 🛡

helmet · rate-limit 300/15m + auth 10/min + AI 20/min · CORS per env · spójne 404/500
